# VANTA/9 store

A fictional streetwear shop built with plain HTML, CSS and JavaScript.

- `products.json`: the product list (edit this to add or change products)
- `site.js`: shared code (cart, header, footer)
- `shop.js`, `product.js`, `cart.js`, `checkout.js`: one script per page
- `functions/api/checkout.js`: Stripe checkout (runs on Cloudflare)
- `images/`: product photos and the hero photo
